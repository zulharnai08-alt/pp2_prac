# TSIS 1: PhoneBook Extended

Проект консольного менеджера контактов с использованием Python и PostgreSQL.

## 🚀 Как запустить проект

1. **Создайте базу данных** в PostgreSQL (через pgAdmin).
2. **Запустите SQL скрипты** (сначала `tsis1_schema.sql`, затем `tsis1_procedures.sql`).
3. **Настройте доступ** в файле `tsis1_config.py` (укажите ваш пароль).
4. **Установите библиотеку**: `pip install psycopg2`
5. **Запустите программу**: `python tsis1_phonebook.py`

## 📁 Состав файлов

* **tsis1_phonebook.py** — основное меню и логика (Python).
* **tsis1_connect.py** — модуль подключения к БД.
* **tsis1_config.py** — ваши логин/пароль от БД.
* **tsis1_schema.sql** — код для создания таблиц.
* **tsis1_procedures.sql** — код для функций и процедур в БД.
* **tsis1_contacts.csv** — пример данных для импорта.

## 🛠 Основные функции

* **Поиск:** По имени, email или телефону через функцию БД.
* **Импорт/Экспорт:** Работа с форматами CSV и JSON.
* **Процедуры:** Добавление телефонов и смена групп через PL/pgSQL.
* **Пагинация:** Постраничный просмотр списка контактов.

## 📖 Как работает навигация (Interactive Nav)

В приложении реализован постраничный вывод контактов (пагинация), чтобы не перегружать экран, если в базе много записей.

### Управление навигацией:
При выборе пункта **2. Nav** в главном меню, используйте следующие клавиши (после ввода буквы нажимайте **Enter**):

*   `n` (Next) — перейти на **следующую** страницу (показать следующие 3 контакта).
*   `p` (Previous) — вернуться на **предыдущую** страницу.
*   `q` (Quit) — **выйти** из режима просмотра в главное меню.

### Техническая часть:
Навигация работает на стороне базы данных с помощью SQL-команд:
*   `LIMIT` — определяет размер страницы (по умолчанию 3 записи).
*   `OFFSET` — определяет, сколько записей нужно пропустить от начала списка.

### Сортировка:
Перед началом навигации программа предложит выбрать способ сортировки:
1. По **имени** (Name).
2. По **дате рождения** (Birthday).
3. По **ID**.
